An Algorithm Makes the Process Explicit

I-001
An algorithm expresses an ordered procedure for transforming a problem state toward a required result.
The computational idea is the explicit procedure itself—not the syntax of a particular programming language.
I-002
Inspect each value and maintain the largest value observed so far.
Only the state required to determine the final maximum needs to be maintained.
I-003
Replace the current maximum whenever a larger value is observed.
This conditional update is the decision step inside the procedure.

Lecturing Guide

Teaching IntentHelp learners distinguish an algorithmic procedure from its later implementation in code.

Learner CheckAsk what information must remain known after each inspected value.
